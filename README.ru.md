# Tway

[English](README.md) | Русский

Tway — кроссплатформенная утилита для уведомлений о стримах.

Она следит за выбранными стримерами и отправляет уведомления, когда кто-то начинает или завершает трансляцию.

Поддерживаются:

- Twitch
- Kick
- YouTube
- W.TV

## Запуск

Windows:

```bash
tway.exe
```

Linux:

```bash
./tway
```

`tway.ico` должен находиться рядом с исполняемым файлом.

При первом запуске Tway автоматически откроет окно настройки.

## Команды

```text
--tui      Открыть состояние стримеров
--setup    Открыть настройки
--logs     Открыть просмотр логов
--config   Использовать другой файл конфигурации
--icon     Использовать другую иконку
```

Пример:

```bash
tway.exe --config ./my-config.yaml --icon ./my-icon.ico
```
